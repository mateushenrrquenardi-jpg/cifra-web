# Primeira Tarefa de Desenvolvimento — Fase 02

## Objetivo

Criar o esqueleto inicial da aplicação web Cifra Web utilizando apenas HTML, CSS e JavaScript.

## Restrições

- Não utilizar frameworks.
- Não criar backend.
- Não implementar pesquisa ainda.
- Não implementar parser de cifras ainda.
- Não implementar favoritos.
- Não implementar transposição.
- Não implementar offline.
- Não adicionar funcionalidades futuras.

## Resultado esperado

Estrutura mínima equivalente a:

```text
/
├── index.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── assets/
```

A página deve abrir sem erros no navegador.

## Interface mínima

Uma interface visual simples que demonstre:

- nome do projeto;
- campo de pesquisa visual;
- área reservada para lista de músicas;
- área reservada para lista de artistas.

Ainda não é necessário que a pesquisa funcione.

## Critérios de aceitação

- HTML válido o suficiente para uso no navegador;
- CSS carregando corretamente;
- JavaScript carregando corretamente;
- nenhum framework;
- nenhum erro de carregamento no console;
- layout responsivo básico;
- projeto preparado para publicação no GitHub Pages.

## Regra de encerramento

Depois que os critérios forem atendidos, fazer commit e somente então avançar para a próxima tarefa.
